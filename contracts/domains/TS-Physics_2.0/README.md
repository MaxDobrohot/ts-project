# TS-Physics_2.0: Домен "Физика"

## 📋 Описание
Базовый акт домена физики в рамках Темпоральной Семиотики.

## 📁 Структура

TS-Physics_2.0/
├── act_2.0.yaml            # Базовый акт (инварианты)
├── subacts/                   # ПодАкты (субдомены)
 │   ├── superconductivity_2.1.yaml
 │   └── ...                       # Новые ПодАкты добавляются, не заменяют
 │   │
 │   ├── shared/                 # Общие ресурсы для всех ПодАктов
 │         ├── schemas/        # YAML-схемы (M4-теги)
 │   │  ├── ontologies/       # Онтологии физики
 │   │  └── metrics/            # Базовые метрики (ε, ΔΓ-шаблоны)
 │   └── README.md          # Описание домена и правила расширения

## ➕ Как добавить новый ПодАкт
1. Создайте файл в `subacts/` с именем `<тема>_<версия>.yaml`
2. Укажите `based_on: "2.0"`
3. Профилируйте уровни под вашу тему
4. Запустите валидацию: `./scripts/run_full_validation_pipeline.sh --subact superconductivity_2.1`

## ✅ Валидация
ПодАкт считается валидным, если:
- Наследует все инварианты из `act_2.0.yaml`
- Не вводит противоречащих `Z`-правил
- Проходит все 4 слоя `TS-Validator`

## ℹ️ Примечание о статусах
- `core_domain` (act_2.0.yaml) — базис для наследования, не подлежит самостоятельной валидации
- `proposed` (subacts/*.yaml) — готов к валидации относительно базиса
- `validated` — прошёл все 4 слоя TS-Validator относительно базового акта
