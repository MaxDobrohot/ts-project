Session Management: Протокол `Z_Context_Preservation`**Правило:** `CONTEXT_SNAPSHOT.md` является B-уровнем памяти проекта. Он гарантирует непрерывность работы при смене сессий (контекстных окон).**Алгоритм перед завершением сессии:**1. Сгенерировать актуальный снапшот:bashbash scripts/generate_context_snapshot.sh2. Закоммитить изменения:bashgit add CONTEXT_SNAPSHOT.mdgit commit -m "docs: update context snapshot [reason]"git push3. В новом окне: Вставить содержимое CONTEXT_SNAPSHOT.md в первое сообщение чата.Зачем: Это превращает потерю контекста из риска в управляемый процесс сворачивания/разворачивания состояния системы.## 2. Как добавить новый ПодАкт (N.1)Добавление домена или ПодАкта требует соблюдения генеративной грамматики (PR_Ω, PR_X3).Шаг 1: СозданиеСкопируйте шаблон:bashcp contracts/templates/act_template.yaml contracts/domains/TS-<DOMAIN>/subacts/<name>.yamlШаг 2: ПрофилированиеЗаполните based_on, уровни (A-F), language_contract и metrics. Важно: Не переопределяйте ядерные Z-правила (см. раздел 3).Шаг 3: ВалидацияЗапустите TS-Validator для конкретного ПодАкта:bashОжидание: ✅ КОНТУР ЗАКРЫТ (все 4 слоя PASS).Шаг 4: КоммитТолько при успешной валидации:bashgit add contracts/domains/...git commit -m "feat: add <name> subact, validated per PR_X3"## 3.
