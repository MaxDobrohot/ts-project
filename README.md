Это гарантирует, что ни одно изменение в contracts/ или validator/ не будет принято, если оно нарушает структурную целостность KVS 1.0.• Scope: Проверка затрагивает только файлы в causal_window (изменённые файлы).• Rollback: При нарушении Z-правил коммит автоматически отклоняется.🌐 Публичный дашбордВизуализация метрик валидации доступна онлайн (режим B-level snapshot): Открыть дашбордПримечание: Дашборд публикует только безопасные метрики (irreal time).
